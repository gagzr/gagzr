### 🚀 Highlighted Projects & Architecture

- **🔒 Hardened Cloud Infrastructure & Secure Vault Architecture**
  * Engineered a zero-trust, self-hosted password infrastructure with **Podman rootless containers**, non-root UID isolation (`2001:2001`), and **SELinux volume contexts** (`:Z`).
  * Automated **ACME DNS-01** challenges via **Cloudflare DNS API** for valid SSL/TLS without exposing public ports, secured across a private **Tailscale Mesh VPN**.

- **🖥️ Virtualized Enterprise Infrastructure & Network Gateway**
  * Bare-metal home lab using **Proxmox VE** hosting containerized **LXC microservices** & isolated VMs.
  * Configured virtualized **OPNsense firewall/router** for packet filtering, network segmentation, and secure inter-VLAN routing with **NGINX reverse proxying**.

- **⚡ SkyVault: Portable Edge Cloud Storage System**
  * Raspberry Pi edge storage system utilizing **mDNS** for zero-configuration local network discovery and high-throughput **Java Spring Boot REST APIs**.
  * Presented research paper at **TSMISDG-2024 International Conference**.

- **📹 [youtube-studio-uploader](https://github.com/gagzr/youtube-studio-uploader)**
  * Headless Playwright automated pipeline designed for containerized & VPS background video uploads without YouTube API quota limits.
