### 🔒 Hardened Cloud Infrastructure & Secure Vault
* **Rootless Podman Architecture**: Self-hosted secure password infrastructure with non-root UID isolation (`2001:2001`) and SELinux volume contexts (`:Z`).
* **Zero-Trust Network**: Automated **ACME DNS-01** challenges via Cloudflare API for 100% valid SSL/TLS without opening public HTTP ports.
* **Encrypted Mesh VPN**: Restricted private app access strictly to authorized **Tailscale Tailnet** peers.
* **NGINX Reverse Proxy**: Configured TLS termination, HTTP/2, WebSocket proxying (`/notifications/hub`), and security headers (HSTS).

* **OPNsense Firewall & Routing**: Virtualized appliance delivering stateful packet filtering, network segmentation, and secure inter-VLAN routing.
* **Traffic Ingress & SSL**: Configured NGINX reverse proxies to route internal traffic across segmented container subnets with automated TLS offloading.
