### 🏗️ Featured Projects & Research

#### 🔒 Hardened Cloud Infrastructure & Secure Vault
- **Rootless Podman Architecture** — Non-root UID/GID namespace isolation with SELinux volume relabeling for a self-hosted secure password vault.
- **Zero-Trust Network** — Automated **ACME DNS-01** challenges via Cloudflare API for valid SSL/TLS without exposing any public HTTP port.
- **Tailscale Mesh VPN** — Restricted private app access exclusively to authorized Tailnet peers.
- **NGINX Hardening** — TLS termination, HTTP/2, WebSocket proxying, HSTS, and strict security headers.

#### 🖥️ Virtualized Enterprise Infra & Network Gateway
- **Bare-Metal Proxmox VE** — Hypervisor hosting isolated LXC microservices and VM environments simulating multi-tenant datacenter patterns.
- **OPNsense Firewall** — Stateful packet filtering, inter-VLAN routing, and network segmentation.
- **Traffic Ingress** — NGINX reverse proxies routing internal traffic across segmented container subnets with automated TLS offloading.

#### ⚡ SkyVault — Portable Edge Cloud Storage
- **Raspberry Pi Edge Device** — Portable offline cloud storage with mDNS for zero-configuration local discovery.
- **Java Spring Boot REST API** — High-throughput file upload, link generation, and zero-dependency media streaming.
- **📜 Published Research** — [*"SkyVault – A Comprehensive Cloud Storage Solution for Raspberry Pi 5"*] at **TSMISDG-2024 International Conference**. 

#### 🤖 [youtube-studio-uploader](https://github.com/gagzr/youtube-studio-uploader)
- **Headless Playwright Pipeline** — Automated metadata injection and upload scheduling via full browser automation, reducing dependency on rate-limited official APIs for bulk operations.
- **Metadata Injection** — Title, description, thumbnails, tags, audience, and visibility — all fully automated.
- **Cookie-Based Auth** — One-time session export for unattended cron-based uploads on Linux servers.
